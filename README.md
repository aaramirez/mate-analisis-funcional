# Análisis funcional

Álgebra lineal en dimensión infinita: espacios de Banach y de Hilbert, operadores acotados, los teoremas de Hahn-Banach, Baire, Banach-Steinhaus, la aplicación abierta y el gráfico cerrado, la dualidad, las bases de Schauder y las topologías débiles.

**Ver en línea:** https://aaramirez.github.io/mate-analisis-funcional/
